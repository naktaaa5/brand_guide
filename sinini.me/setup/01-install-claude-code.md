# ① 클로드 코드 설치 (왕초보용)

> 대시보드에 내 인스타 데이터를 연결하려면, 내 컴퓨터에서 **Claude(클로드 코드)**가 메타(인스타) 설정을 대신 해줘야 해요.
> 그러려면 딱 한 번 **클로드 코드를 설치**하면 됩니다. 아래만 천천히 따라오세요.
> **막히면 절대 끙끙대지 말고** 캡처해서 보내주시면 같이 봐드려요. (이 5분이 제일 큰 고비예요.)

---

## 이게 뭔가요?
- **클로드 코드** = 내 컴퓨터에서 시키는 일을 대신 해주는 AI 도구예요. (채팅 클로드의 ‘일하는’ 버전)
- 설치는 **딱 한 번**. 그다음부턴 “이거 해줘”라고 파일만 주면 됩니다.

---

## 준비물
- 인터넷 되는 컴퓨터(윈도우 또는 맥)
- 메타(페이스북) 로그인 정보 + 문자 받을 핸드폰
- 인스타가 **비즈니스/크리에이터 계정**이고 **페이스북 페이지에 연결**돼 있으면 좋아요. (안 돼 있어도 클로드가 안내해줍니다)

---

## 설치 (윈도우)

**1) ‘터미널’ 열기**
- 화면 왼쪽 아래 **시작(⊞)** 버튼 → `terminal` 또는 `powershell` 이라고 치면 나오는 **PowerShell**을 클릭해서 엽니다.
- 까만(또는 파란) 글자 창이 뜨면 성공이에요.

**2) 아래 한 줄을 복사해서 붙여넣고 Enter**
```
irm https://claude.ai/install.ps1 | iex
```
- 설치가 자동으로 진행됩니다. (몇 분 걸려요. 글자가 막 지나가도 정상이에요.)

**3) 로그인**
- 설치가 끝나면 창에 `claude` 라고 치고 Enter.
- “로그인하라”는 안내가 뜨면 → 안내된 주소를 브라우저에서 열어 **클로드 계정으로 로그인**하면 끝.

> 맥(Mac)이면 ‘터미널(Terminal)’ 앱을 열고:
> ```
> curl -fsSL https://claude.ai/install.sh | bash
> ```

---

## 잘 됐는지 확인
- 창에 `claude` 치고 Enter 했을 때 **클로드가 인사**하면 설치 완료예요.

## 막히면

- (구독료 안내: 클로드 코드는 유료예요. 비용은 미리 알려드릴게요.)
