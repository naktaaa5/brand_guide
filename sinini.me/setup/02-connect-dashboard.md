## 〈여기서부터는 클로드가 읽고 실행하는 부분〉

**클로드에게 — 이 블록을 그대로 따른다:**
너는 지금 미용실 원장님(이시니님)을 돕는다. 이분은 **AI·개발이 처음**이다.
- 전문용어 금지. **한 번에 한 단계씩.** 매 단계 “지금 무엇을·왜”를 한 줄로 쉽게.
- 네가 **못 하는 것(로그인·문자 인증·동의 클릭)** 이 나오면 **멈추고 쉬운 말로 부탁**해라. 예: “이 화면에서 ‘확인’을 눌러주세요”, “문자로 온 6자리 숫자를 불러주세요.”
- 비밀번호는 **받아 적지도 저장하지도 마라.** 로그인은 원장님이 직접.
- 막히면 추측 말고 물어라. 끝나면 **“완료됐어요”** 라고 알려라.
- **목표: 그래프 API에서 데이터를 받아 → 대시보드 폴더에 `data.js` 파일을 만들면 → 대시보드가 자동으로 실데이터로 바뀐다.** (대시보드 코드는 손대지 마라. `data.js`만 만들면 된다.)

### 단계 (간략)
1. **브라우저 준비** — `chrome-devtools` MCP로 디버그 크롬을 띄우고, 원장님께 **“뜬 창에서 메타(페이스북)에 로그인해주세요”** 부탁. (이후 모든 작업은 이 세션에서)
2. **계정 확인** — 인스타가 **비즈니스/크리에이터 + 페이스북 페이지 연결** 상태인지 확인. 안 돼 있으면 폰으로 전환하도록 쉽게 안내.
3. **앱·토큰** — `developers.facebook.com`에서 비즈니스 앱 생성(이름 예: `이시니 대시보드`) → **Instagram 그래프 API** 추가 → 권한 `instagram_basic, instagram_manage_insights, pages_show_list, pages_read_engagement` 허용 → **장기 토큰(약 60일)** 발급. (본인 계정만 보니 앱 심사 없이 개발모드 + 원장님을 관리자/테스터로.) *문자 인증 뜨면 코드 요청.*
4. **데이터 수집** — 토큰으로 그래프 API 호출: 팔로워 수, 최근 게시물(미디어) 목록 + 게시물별 인사이트(도달·노출·좋아요·댓글·저장·공유·평균시청·프로필 방문·팔로우 전환).
5. **`data.js` 작성** — 대시보드(`dashboard.html`)와 **같은 폴더**에 아래 형식으로 `data.js`를 만든다. (숫자는 사람이 읽기 쉬운 문자열로, 예: `"1,596,000"`)
6. **확인** — 대시보드를 새로고침. 우상단 배지가 **“● 실데이터”** 로 바뀌고 숫자·차트가 채워지면 완료. 안 뜨면 `data.js` 문법(콤마·따옴표)·토큰 유효성을 되짚는다.

### `data.js` 형식 (이대로 채운다)
```js
window.LIVE_DATA = {
  profile: {
    followers: "3,133", followersChg: "▲ 2.1% vs 지난달",
    er: "2.4%",         erChg: "▲ 0.5%p vs 지난달",
    views30: "281K",    views30Chg: "▲ 18% vs 지난달",
    saves: "1,242",     savesChg: "▼ 4% vs 지난달"
  },
  trend: { labels: ["일","월","화","수","목","금","토"], data: [320,410,584,360,540,470,300], avg: 426 }, // 최근 7일 일별 조회
  byType: { labels: ["변신","진단","서사","꿀팁","시술"], data: [420,150,330,95,110] }, // 유형별 평균 반응(클로드가 캡션으로 유형 분류)
  reach: { newPct: 62, loyalPct: 38 }, // 도달(새 사람) vs 연결(팔로워) 비율 — 인사이트에 있으면 사용, 없으면 추정
  posts: [
    {
      id: "p1",                       // 아무 고유값
      t: "게시물 제목(캡션 첫 줄 요약)",
      p: "DMCQ3iHS-Bu",               // 릴스 permalink 의 코드(.../reel/여기/)
      type: "변신",                    // 변신/진단/서사/꿀팁/시술 등
      ago: "1주 전",
      ic: "🎀",                        // 아무 이모지
      er: "0.3%",                      // 참여율
      m: { "도달":"1,596,000","노출":"2,010,000","좋아요":"3,547","댓글":"51","저장":"210","공유":"480","평균시청":"7.2초","프로필 방문":"2,140","팔로우 전환":"86" },
      note: "이 게시물을 어떻게 읽어야 하는지 한 줄 코멘트"
    }
    // … 게시물 5~10개
  ]
};
```
> 게시물 ‘성과 베스트’와 ‘최근 게시물’ 목록은 대시보드가 위 `posts`로 **자동 계산**한다. 너는 `posts`만 채우면 된다.
