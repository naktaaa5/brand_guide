# ② 대시보드 연결 런북 (클로드 코드가 실행)

> **클로드에게 (이 블록을 그대로 따른다):**
> 너는 지금 미용실 원장님(이시니님)을 돕는다. 이분은 **AI·개발이 처음**이다.
> - 전문용어 금지. 한 번에 **한 단계씩**. 매 단계 “지금 무엇을·왜” 한 줄로 쉽게 설명.
> - **네가 할 수 없는 것(로그인·문자인증·동의 클릭)**이 나오면 **멈추고 쉬운 말로 부탁**해라. 예: “지금 화면에서 ‘확인’을 눌러주세요”, “문자로 온 6자리 숫자를 불러주세요.”
> - 절대 원장님 비밀번호를 받아 적거나 저장하지 마라. 로그인은 **원장님이 직접** 하게 한다.
> - 막히면 추측하지 말고 물어봐라. 끝나면 “완료됐어요”라고 알려라.
> - 목표: **메타 장기토큰을 발급해 대시보드에 넣고, 차트가 뜨는 것까지.**

---

## 0단계 — 브라우저 운전 준비 (클로드)
- `chrome-devtools` MCP가 없으면 설치하고, 디버그 모드 크롬을 띄운다.
- 원장님께: **“뜬 크롬 창에서 페이스북(메타)에 로그인해주세요”** 라고 부탁한다. (이후 모든 메타 작업은 이 로그인 세션에서)

## 1단계 — 인스타 계정 상태 확인
- 원장님 인스타가 **비즈니스/크리에이터 계정 + 페이스북 페이지 연결**인지 확인.
- 안 돼 있으면: 인스타 앱 → 설정 → ‘프로페셔널 계정 전환’ + 페이지 연결을 **쉬운 말로 안내**(원장님이 폰으로 수행). 되면 다음.

## 2단계 — 메타 개발자 등록 + 앱 만들기
- `developers.facebook.com` 접속 → 개발자 등록(처음이면). **문자 인증이 뜨면 원장님께 코드 요청.**
- ‘앱 만들기’ → 유형 **비즈니스(Business)** → 앱 이름 예: `이시니 대시보드`.
- 앱에 **Instagram(그래프 API)** 제품을 추가한다.

## 3단계 — 계정/페이지 연결 확인
- 앱에서 원장님의 **페이스북 페이지**와 **인스타 비즈 계정**을 연결/선택한다.
- (지난번 토큰이 막힌 가장 흔한 원인 = 이 연결·역할 누락이니 꼼꼼히.)

## 4단계 — 권한(스코프) 켜기
- 다음 권한을 요청/허용: `instagram_basic`, `instagram_manage_insights`, `pages_show_list`, `pages_read_engagement`.
- 본인 계정만 볼 거라 **앱 심사 없이** 개발 모드 + 원장님을 **테스터/관리자**로 추가하면 동작한다.

## 5단계 — 장기토큰 발급
- ‘그래프 API 탐색기(Graph API Explorer)’에서 위 권한으로 **단기 토큰**을 받는다.
- 단기 → **장기 토큰(약 60일)** 으로 교환한다.
- (확인) 클로드가 `me?fields=id,username` 같은 호출로 토큰이 **살아있는지 테스트**한다. `code 200 API access blocked`가 또 나오면 2~4단계의 연결/역할/권한을 되짚는다.

## 6단계 — 대시보드에 넣기
- 받은 장기토큰을 **대시보드 페이지의 토큰 칸**에 붙여넣는다(또는 클로드가 넣어준다).
- 새로고침 → 팔로워·조회·저장·게시물별 지표 차트가 **실데이터로** 뜨면 완료.

## 7단계 — 60일 갱신 안내
- 원장님께: **“약 두 달 뒤 숫자가 안 보이면, 클로드 코드에 이 파일을 다시 주고 ‘토큰 갱신해줘’ 라고만 하세요”** 라고 알려준다.
- (원하면 자동 갱신 서버는 나중에 별도로 만든다.)

### 클로드 체크리스트

- [ ] 로그인·문자코드·클릭은 원장님께 부탁(비밀번호 저장 금지)
- [ ] 토큰 살아있는지 테스트하고 차트 뜨는 것 확인
- [ ] 막히면 질문, 끝나면 “완료” 보고
